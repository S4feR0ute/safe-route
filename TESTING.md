# Reporte de Testing - SafeRoute

## Sprint 1

## Objetivo

Validar las funcionalidades básicas implementadas en el frontend de la aplicación SafeRoute.

## Casos de prueba

### Caso 1: Visualización del mapa

 **Acción:** Abrir la aplicación
 **Resultado esperado:** El mapa debe mostrarse correctamente
 **Resultado obtenido:** El mapa se carga correctamente

### Caso 2: Validación de campos

 **Acción:** Intentar buscar ruta sin ingresar datos
 **Resultado esperado:** Mostrar mensaje de error
 **Resultado obtenido:** El sistema muestra mensaje correctamente


### Caso 3: Búsqueda de ruta

 **Acción:** Ingresar origen y destino y hacer clic en buscar
 **Resultado esperado:** Iniciar proceso de búsqueda
 **Resultado obtenido:** Se muestra indicador de carga 

## Conclusión

El sistema cumple con los requerimientos del Sprint 1, permitiendo la interacción básica del usuario y validación de entradas.
Las funcionalidades avanzadas, como el cálculo de rutas, se encuentran en desarrollo.
